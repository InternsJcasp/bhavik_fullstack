## How to run this Project:

## About My Project:

- Made CRUD Employee app with Search, Filter, Pagination, using JSON API, Axios, HTTP Methods, JSON Data in React + Tailwind.
- In this You can create, read, update and delete Employees.

### Simply Open Two terminals:

- In first Terminal type this command:

```bash
npm run server
```

- In second Terminal type this command:

```bash
npm run dev
```
